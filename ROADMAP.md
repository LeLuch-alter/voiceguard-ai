# План работ — VoiceGuard AI

## Цель проекта

ИИ-оператор для коммерческих компаний, который снижает (не обнуляет) затраты на сотрудников,
делает общение ровным и удобным, полностью защищённым с обеих сторон, с главным акцентом
на голосовое общение.

Три опоры (= название): **Voice** (голос) · **Guard** (защита) · **AI** (оператор-помощник).

### Принципы
- Человек остаётся в контуре: ИИ берёт рутину, сложное эскалирует на сотрудника.
- Приватность по умолчанию: не логировать переписку/аудио на сервере, ключи только на бэке.
- Отраслевая нейтральность и настраиваемость под любую компанию.
- Простой стек без сборки (статика + serverless на Vercel + GROQ).

---

## Голосовой цикл (как устроен голос)

```
Микрофон (MediaRecorder) -> STT (речь->текст) -> LLM (ответ) -> TTS (текст->речь) -> динамик
```

- **STT:** GROQ Whisper (`whisper-large-v3-turbo`) — быстрый, дешёвый, RU/EN/KZ, тот же провайдер.
- **TTS:** старт — браузерный `SpeechSynthesis` (бесплатно, локально, приватно); далее облачный
  TTS (ElevenLabs / GROQ PlayAI) для живого голоса.
- **Естественность (позже):** VAD (определение конца речи), прерывание, стриминг; в перспективе —
  OpenAI Realtime API / Vapi / LiveKit; для телефонии — Twilio.
